# 🌦️ Weather Tracker | by Somesh Raj

A sleek and modern **Weather Tracker App** built using **HTML, CSS, and JavaScript**, powered by the **OpenWeather API** 🌍.  
It gives you **real-time weather updates**, beautiful **animated backgrounds**, and a smooth, interactive UI — all in one clean package! 💫

---

## 🧠 About the Project

This app allows users to **search any city** and instantly see:
- 🌡️ Temperature (°C)
- ☁️ Weather condition
- 💧 Humidity
- 🌬️ Wind speed
- 🌈 Pressure

It also features a **dynamic gradient background**, floating **bubble animation**, and a **custom alert system** for better user experience.  
All designed to make checking the weather a little more fun! 😄

---

## 💻 Tech Stack

- 🧱 **HTML5** – Structure & layout  
- 🎨 **CSS3** – Styling, gradient animations & responsiveness  
- ⚙️ **JavaScript (Vanilla JS)** – Logic, interactivity & API integration  
- ☁️ **OpenWeather API** – Real-time weather data  

---

## ⚙️ How It Works

1. Type any **city name** in the search bar 🔍  
2. Click **Search** or press **Enter** ⌨️  
3. Instantly view temperature, weather type & details 🌡️  
4. Background changes dynamically with smooth animation ✨
